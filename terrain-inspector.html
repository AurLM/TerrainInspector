See your landscape before you launch the game

This page reads your plugins (.esm / .esp / .esl) directly in your browser. Nothing is uploaded: the files never leave your computer. It draws the final terrain of your load order, shows which mod controls each cell, and flags cell borders that won't blend.

What do you use to install your mods?

1

Pick your plugins

Pick your game's Data folder, e.g. C:\Program Files (x86)\Steam\steamapps\common\Skyrim Special Edition\Data. Vortex puts every mod there, so that's all the tool needs (plus your load order in step 2).

The tool finds the mods, the profile with its load order, and the game inside it. A checklist below shows what was found and what, if anything, is still needed.
If something is stored elsewhere (game installed in Steam, mods in a shared folder), just add that folder too. You can add as many folders as you need, in any order.

Browser says the folder "contains system files" or won't open it? That happens with folders under Program Files or AppData. Open the folder in File Explorer and drag it onto this page instead: dragging always works.

or drag a folder / files here
2

Load order (recommended)

Your load order is the file plugins.txt. It lives in a hidden folder, so the easiest way is:

  1. Click Copy path: %LOCALAPPDATA%\Skyrim Special Edition\plugins.txt
  2. Click Pick load order file…, paste the path into the File name box of the window that opens, and press Enter.

GOG copy: Skyrim Special Edition GOG instead of Skyrim Special Edition. Epic: Skyrim Special Edition EPIC. You can also drag plugins.txt onto this page.

Done automatically if you picked the whole MO2 folder. Otherwise pick plugins.txt and modlist.txt from MO2\profiles\<profile name>\ (modlist.txt tells which mod's copy of a plugin wins).

Without a load order the order is guessed from the files' dates.

…or paste your plugin list

One plugin per line, first loaded at the top: the contents of plugins.txt, or a list copied from LOOT / your mod manager. Lines starting with * are enabled; if no line has a *, every listed plugin counts as enabled.
