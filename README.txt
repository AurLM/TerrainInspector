TERRAIN INSPECTOR - Windows version

Unzip the whole "Terrain Inspector" folder anywhere, then double-click "Terrain Inspector.exe".
Nothing to install on Windows 10 and 11. Works with any mod manager (MO2, Vortex, Wabbajack, Nolvus) and manual installs.

What is in the folder:
  Terrain Inspector.exe              the window (a small program; the tool itself is the page below)
  page\terrain-inspector.html        the tool. You can also open it in a browser: it is the same tool.
  Microsoft.Web.WebView2.*.dll,      Microsoft's files to show the page in the window
  WebView2Loader.dll

The program doesn't connect to the internet, doesn't need admin rights and installs nothing.
Its only saved data (settings, remembered folders) is in %LOCALAPPDATA%\TerrainInspector. Delete that folder to reset it.
